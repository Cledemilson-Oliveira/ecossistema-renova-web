# Ecossistema RENOVA Web

Interface pública do Ecossistema RENOVA.

Esta camada Web é publicada pelo GitHub Pages e se conecta ao Supabase do Ecossistema RENOVA.

O código-fonte principal, regras internas e backend permanecem no repositório privado `ecossistema-renova`.

## Segurança

Este repositório pode conter apenas informações públicas necessárias ao navegador, como URL do Supabase e chave pública/publishable. Nunca adicionar `service_role`, Access Token do Mercado Pago, senhas ou outros segredos privados.
